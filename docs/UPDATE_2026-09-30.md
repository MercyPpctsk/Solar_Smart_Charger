## 1. ภาพรวมการอัปเดต (Summary of Changes)

การอัปเดตในรอบนี้มุ่งเน้นการเพิ่มประสิทธิภาพการบริหารจัดการระบบผ่าน **Web UI Configuration Portal (`setup_web.h`)** เพื่อให้ผู้ดูแลระบบสามารถปรับเทียบค่าความคลาดเคลื่อนของแรงดัน (Voltage Calibration) และกำหนดการบำรุงรักษาระบบอัตโนมัติ (Periodic Auto-Reboot) ได้อย่างสะดวก ปลอดภัย และไม่กระทบต่อความต่อเนื่องของการวัดค่า

## 2. ฟังก์ชันใหม่ที่เพิ่มเข้ามา

### 2.1 แท็บใหม่ใน Web Portal: `⚙️ Calibration & System` (`#tab_cal`)
บนหน้า Web UI Configuration Portal (`http://192.168.4.1/` หรือ IP วงเครือข่าย) มีการเพิ่มแท็บการตั้งค่าที่ 3 ซึ่งประกอบด้วย 2 ส่วนหลัก:

#### 1. Voltage Offset Calibration (การปรับเทียบชดเชยแรงดัน)
- **Solar Panel Voltage Offset (V)**: ช่องกรอกค่าชดเชยแรงดันแผงโซลาร์เซลล์ (ช่อง A0)
- **Battery Voltage Offset (V)**: ช่องกรอกค่าชดเชยแรงดันแบตเตอรี่ (ช่อง A1)
- **ความละเอียดและการควบคุม**: สเต็ปละเอียดถึง `0.001 V` (1 mV) พร้อมระบบความปลอดภัยจำกัดขอบเขต (Range Check) ที่ `±1.000 V` ป้องกันการใส่ค่าผิดพลาด
- **Hot-Apply (มีผลทันทีโดยไม่ต้อง Reboot)**:
  - เมื่อกดบันทึก โค้ดจะบันทึกค่าลง NVS namespace `"solarcal"` (คีย์ `vsOfs`, `vbOfs`) เพื่อจำข้ามรอบบูต
  - ส่งสัญญาณผ่านแฟล็ก `g_calChanged` ให้อัปเดตตัวแปรใน RAM (`vSolarOffsetV`, `vBattOffsetV`) ทันที
  - ในรอบการคำนวณถัดไปของ Core 1 (ภายใน ~5.6 วินาที) ค่าแรงดันที่แสดงผลและค่าที่ส่งขึ้น ThingsBoard จะเปลี่ยนตามค่าชดเชยใหม่ทันที **โดยบอร์ดไม่ต้องรีเซ็ต ไม่ขาดการเชื่อมต่อ WiFi/SoftAP และไม่สะดุดการนับ SoC/Energy**
- **ซิงก์สองทางกับคำสั่ง Serial**:
  - หากปรับค่าผ่าน Serial Monitor (`V<x>`, `P<x>`) หน้า Web UI จะแสดงค่าตามอัตโนมัติ
  - หากปรับค่าผ่าน Web UI คำสั่ง Serial `t` ก็จะแสดงค่าตรงกัน 100%

#### 2. Automated Maintenance (ระบบรีบูตอัตโนมัติตามระยะเวลา)
- **Enable Periodic Auto-Reboot Checkbox**: สวิตช์เปิด/ปิดการทำงานของฟังก์ชันรีบูตอัตโนมัติ
- **Reboot Interval (Hours)**: ช่องกำหนดระยะเวลาที่ต้องการให้บอร์ดรีบูตตัวเอง (กำหนดได้ 1 ถึง 720 ชั่วโมง, ค่าเริ่มต้น 24 ชั่วโมง)
- **ความปลอดภัยและการป้องกันข้อมูลสูญหาย**:
  - เมื่อถึงรอบรีบูต ระบบจะทำการ Flush ข้อมูล SoC (State of Charge), ข้อมูล SoH Throughput และบรรทัด Log CSV ล่าสุดลงใน Flash memory ก่อนเสมอ
  - มีระบบหน่วงเวลา Serial Drain (100ms) ก่อนสั่ง `ESP.restart()`
  - มีระบบป้องกัน Boot-loop ขั้นต่ำ 5 นาที (`RST_MIN_UPTIME_MS`) ป้องกันเครื่องวนลูปรอบูต

#### 3. การแจ้งเตือนและการควบคุมอื่นๆ
- **Save Alert Box**: เมื่อกดปุ่ม **"Save Calibration & System"** หน้าเว็บจะรีเฟรชกลับมาพร้อมกล่องแจ้งเตือนสีเขียว Cyberpunk:
  `✔ Calibration & System settings saved successfully! Changes are live.`
- **Manual Restart Button**: ปุ่มสีแดง **"Restart Device Now"** พร้อมกล่อง Confirm ยืนยัน สำหรับกรณีที่ต้องการสั่งรีบูตฮาร์ดแวร์ด้วยมือทันที

## 3. รายละเอียดการแก้ไขซอร์สโค้ด

### 3.1 ไฟล์ `src/setup_web.h`
1. เพิ่มฟิลด์ในโครงสร้าง `struct AppConfig`:
   ```cpp
   float    vsolar_offset   = 0.0f; // V (-1.0 to +1.0)
   float    vbatt_offset    = 0.0f; // V (-1.0 to +1.0)
   bool     reboot_en       = true; // Periodic auto-reboot enabled
   uint16_t reboot_hours    = 24;   // Hours (1 to 720)
   ```
2. เพิ่มแฟล็ก `g_calChanged = false;`
3. ปรับปรุง `loadAppConfig()` ให้อ่านค่า `vsOfs` และ `vbOfs` จาก `"solarcal"` และ `rb_en`, `rb_h` จาก `"app_cfg"`
4. เพิ่มฟังก์ชัน `saveCalConfig(float vSolarOfs, float vBattOfs, bool rebootEn, uint16_t rebootHours)`
5. เพิ่มปุ่มแท็บ `#tab_cal` และเนื้อหาฟอร์มใน `#panel_cal`
6. เพิ่มตัวจัดการ Route `_handleSaveCal()` และผูก URL `/save_cal` (HTTP POST) ใน `setupWebBegin()`

### 3.2 ไฟล์ `src/main.cpp`
1. เพิ่มการตรวจจับแฟล็ก `g_calChanged` ในลูปหลัก `loop()`:
   ```cpp
   if (g_calChanged) {
     g_calChanged = false;
     vSolarOffsetV = appConfig.vsolar_offset;
     vBattOffsetV  = appConfig.vbatt_offset;
     Serial.printf("[CAL ] Live offsets updated from Web UI: solar=%+.3fV, batt=%+.3fV\n",
                   vSolarOffsetV, vBattOffsetV);
   }
   ```
2. ซิงก์ค่า `appConfig.vbatt_offset` และ `appConfig.vsolar_offset` ในคำสั่ง Serial `setVbattOffset`, `clearVbattOffset`, `setVsolarOffset`, `clearVsolarOffset`
3. ปรับปรุงฟังก์ชัน `serviceDailyRestart()` ให้รองรับ:
   - ตรวจสอบ `if (!appConfig.reboot_en) return;` (หากปิดสวิตช์ จะไม่รีบูต)
   - กรณีตั้ง 24 ชม. และมีเวลา NTP: รีบูตเวลา `00:01 น.` ประจำวัน
   - กรณีตั้งค่าชั่วโมงอื่นๆ หรือไม่มีเวลา NTP: ตรวจจับจาก Uptime สะสมเมื่อครบชั่วโมงที่กำหนด

## 4. ตารางคีย์ NVS (Non-Volatile Storage)

| Namespace | Key | Type | Default | คำอธิบาย |
|---|---|---|---|---|
| `solarcal` | `vsOfs` | float | `0.0f` | Solar panel voltage offset (V) |
| `solarcal` | `vsOfsOk` | bool | `false` | สถานะความถูกต้องของ solar offset |
| `solarcal` | `vbOfs` | float | `0.0f` | Battery voltage offset (V) |
| `solarcal` | `vbOfsOk` | bool | `false` | สถานะความถูกต้องของ battery offset |
| `app_cfg` | `rb_en` | bool | `true` | สวิตช์เปิด/ปิด Periodic Auto-Reboot |
| `app_cfg` | `rb_h` | uint16 | `24` | ระยะเวลารอบการรีบูต (ชั่วโมง) |
